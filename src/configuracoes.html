Integração Google Sheets

Configure a fonte de dados principal

Encontre o ID na URL da sua planilha: docs.google.com/spreadsheets/d/ID/

Necessário para acessar planilhas privadas via Google Cloud Console

Como conectar ao Google Sheets

  1. 1. Acesse Google Cloud Console e crie um projeto
  2. 2. Ative a API Google Sheets
  3. 3. Crie uma Chave de API em "Credenciais"
  4. 4. Torne a planilha pública ou compartilhe com a conta de serviço
  5. 5. Cole o ID da planilha e a chave API nos campos acima
