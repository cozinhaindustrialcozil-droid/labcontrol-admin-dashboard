PROJETO: Dashboard de Gestão de Solicitações de Testes de Laboratório

Basear o sistema no template TailAdmin já instalado.

OBJETIVO:
Transformar o painel em um sistema corporativo para gerenciamento de solicitações de testes de laboratório, utilizando como fonte de dados uma Planilha Google (Google Sheets) já existente.

VISUAL:

* Manter o layout profissional do TailAdmin.
* Utilizar identidade visual industrial/laboratório.
* Design clean e executivo.
* Responsivo para desktop e tablet.
* Dashboard semelhante a sistemas ERP/MES corporativos.

FONTE DE DADOS:
Google Sheets.

Colunas disponíveis:

* Carimbo de data/hora
* Data da Solicitação
* Nº Solicitação
* Nome do Solicitante
* Nome do Cliente
* Setor Solicitante
* Descrição / Tipo de Equipamento
* Código do Produto / Componente
* Número de Série
* Objetivo do Teste
* Resultado Esperado
* Motivo da Solicitação
* Prioridade
* Previsão de Devolutiva
* Fotos do Equipamento
* Documentos Complementares
* Status
* Responsável Técnico
* Conclusão Técnica
* Melhorias Identificadas
* Data de Finalização

MENU LATERAL:

Dashboard
Solicitações
Kanban
Calendário
Relatórios
Indicadores
Configurações
